## 3. Scope
### Allowed Scope
- Script `ml/src/baselines.py` (chạy được cả CPU máy Tín) và notebook `ml/notebooks/T01_baselines.ipynb` gọi script đó.
- Đầu vào `text_norm`, nhãn `has_negative`, chia `train/dev/test.csv` từ T00.
- Vectorizer: n-gram từ (1,2); thử thêm n-gram ký tự (2,5) và kết hợp (FeatureUnion).
- Grid nhỏ chọn trên **dev**: `alpha` (NB), `C` (LR, SVM), `min_df`, `sublinear_tf`.
