## 1. Objective
Admin thêm, sửa, ngừng chiếu phim ngay trên web; phim mới xuất hiện ở trang chủ và menu lọc.

## 2. Context
BOI_CANH mục 9.2 T04; ARCHITECTURE 2.1–2.4.

## 3. Scope
### Allowed Scope
- API `GET/POST /api/admin/movies`, `PUT/DELETE /api/admin/movies/{id}`.
- Trang `/quan-tri/phim`: bảng danh sách + form thêm/sửa (màu `poster_bg`/`poster_fg` hoặc `poster_url`, có xem trước `Poster`).
- Mục "Quản lý phim" trong menu tài khoản admin.
- Mock hỗ trợ đủ.

### Out of Scope
- Upload ảnh poster lên server. Sửa `movies.json` gốc (dữ liệu tạo qua admin chỉ nằm trong DB / mock storage).

## 4. Thiết kế
- **Backend:** router mới `backend/app/routers/admin_movies.py`, mọi route `Depends(require_admin)`.
  - `POST` body `MovieIn` (Pydantic): `title` (không rỗng, ≤ 200), `genre` (list, mỗi mục thuộc danh sách thể loại), `duration_min` > 0 và ≤ 400, `age_rating` ∈ {P, T13, T16, T18}, `release_date` YYYY-MM-DD hợp lệ, `status` ∈ {now_showing, coming_soon, ended}, `country`, `formats` ⊂ {Phụ đề, Lồng tiếng}, `director`, `cast`, `description`, `poster_bg`/`poster_fg` dạng `#rrggbb`, `poster_url` tùy chọn (http/https). Trả `MovieOut`, 201.
  - `PUT /{id}`: cùng kiểm tra; 404 nếu không có.
  - `DELETE /{id}`: phim chưa có booking → xóa (kèm suất chiếu chưa có vé); đã có booking → 409 `"Phim đã có vé, không xóa được. Hãy chuyển trạng thái sang Đã chiếu xong."`.
  - Danh sách thể loại / quốc gia hợp lệ đặt ở `backend/app/taxonomy.py`, khớp `frontend/src/utils/taxonomy.js`.
- **Frontend:** `pages/AdminMovies.jsx`, route trong `App.jsx` dưới `ProtectedRoute adminOnly`; `api.admin.movies.{list,create,update,remove}` trong `real.js` **và** `mock.js`.
- Form báo lỗi theo từng ô, văn phong BOI_CANH mục 4.
