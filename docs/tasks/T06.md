## 1. Objective
Admin xác nhận, đổi nhãn hoặc ẩn bình luận; trang phim ưu tiên nhãn người duyệt; có thống kê model đúng/sai và file CSV để train tiếp.

## 2. Context
BOI_CANH mục 9.2 T06. Dữ liệu duyệt dùng được cho T03 / T09.

## 3. Scope
### Allowed Scope
- Bảng `comments` thêm: `human_label` (int, null), `reviewed_by` (FK users, null), `reviewed_at` (datetime, null), `hidden` (bool, mặc định false).
- `PATCH /api/admin/comments/{id}` body `{action: "confirm" | "relabel" | "hide" | "unhide", label?: 0|1}`.
- `GET /api/admin/comments` thêm lọc `reviewed=true|false`, phân trang `page`, `page_size` (mặc định 20, tối đa 100), trả `{items, total}`.
- `GET /api/admin/comments/stats` → `{reviewed, agree, disagree, accuracy, tp, fp, tn, fn}` (so `is_negative` với `human_label`).
- `GET /api/admin/comments/export.csv` → `text,text_norm,label` cho bình luận đã duyệt (label = `human_label`).
- Trang `/quan-tri/binh-luan` thêm nút thao tác, khu thống kê, nút "Tải CSV".

### Out of Scope
- Thay đổi model, ngưỡng.

## 4. Thiết kế
- **Không sửa `is_negative`, `negative_score`, `model_name`** khi duyệt.
- Hiển thị công khai: `hidden=true` → ẩn; ngược lại nhãn hiệu lực = `human_label` nếu có, không thì `is_negative`. `GET /api/movies/{id}/comments` thêm `effective_negative`, `reviewed`.
- `text_norm` trong CSV tạo bằng `normalize()`. CSV mã hóa UTF-8 có BOM để Excel đọc đúng tiếng Việt.
- `relabel` không có `label` hợp lệ → 422.
- Response `/api/admin/comments` đổi dạng → cập nhật `real.js`, `mock.js`, `AdminComments.jsx` cùng lúc.
