## 1. Objective
Web chấm bình luận bằng PhoBERT B, mỗi bình luận ghi rõ phiên bản model, vẫn quay lại model A được bằng một dòng `.env`.

## 2. Context
BOI_CANH mục 9.2 T10; nợ kỹ thuật "`model_name` chưa có phiên bản".

## 3. Scope
### Allowed Scope
- Registry T07 nạp thêm `phobert_b` từ `models/phobert-binhluan-B/`; giữ `phobert` (A).
- `MODEL_VERSION` cho từng model (đọc từ `.env` hoặc file `version.txt` trong thư mục model).
- Bảng `comments` thêm `model_version` (chuỗi, null cho dữ liệu cũ).
- `/api/health` và `/api/admin/predict` trả `version`.
- `ml/test_sentences.json`: bộ 10 câu kiểm thử cố định (có "Phim dài lê thê, xem mà mệt") kèm điểm kỳ vọng từ notebook T09.
- Script `backend/scripts/check_model.py` chấm 10 câu và so với kỳ vọng.

### Out of Scope
- Admin đổi model trên giao diện (chờ Q3).

## 4. Thiết kế
- `.env`: `ACTIVE_MODEL=phobert_b`, `MODEL_DIR_B=models/phobert-binhluan-B`, `MODEL_VERSION_A`, `MODEL_VERSION_B`.
- Trang kiểm duyệt hiện `model_name` + `model_version`.
