## 1. Objective
Bộ `pytest` chạy được không cần file PhoBERT, bao phủ các luồng quan trọng; sửa lỗi phát hiện được, ghi vào `CHANGELOG.md`.

## 2. Context
BOI_CANH mục 9.2 T11. Từ task này, `pytest` trở thành gate bắt buộc cho mọi task web.

## 3. Scope
### Allowed Scope
- `backend/tests/` với `conftest.py`: DB SQLite tạm (file trong thư mục tạm hoặc `:memory:` với StaticPool), override `get_db`, classifier giả lập (từ khóa cố định, không nạp torch).
- Test: đăng ký / đăng nhập / `me`; token sai, hết hạn; đặt vé thành công, trùng ghế 409, quá 8 ghế, ghế không hợp lệ; luật VIP khớp `seats.py`; phân quyền admin 401/403 trên **mọi** endpoint `/api/admin/*`; tạo bình luận lưu điểm; T04 kiểm tra dữ liệu và xóa phim có vé; T05 chồng giờ; T06 duyệt không đổi điểm gốc, CSV; T07 thiếu model vẫn chạy; health.
- Thêm `pytest`, `httpx` (TestClient cần) vào `backend/requirements-dev.txt`.
- Sửa lỗi phát hiện được trong `backend/app/**`, mỗi lỗi có test tái hiện.
- Kiểm tay giao diện theo checklist, sửa lỗi frontend nếu có.

### Out of Scope
- Test frontend tự động (Vitest / Playwright). Refactor không liên quan lỗi.

## 4. Thiết kế
- Có thể cần cho phép tắt nạp model khi test: biến môi trường `CLASSIFIER=fake` hoặc dependency override — chọn cách ít đụng code nhất, ghi trong report.
- `CHANGELOG.md` ở thư mục gốc, mục `[Unreleased]`, mỗi lỗi: mô tả, nguyên nhân, test.
