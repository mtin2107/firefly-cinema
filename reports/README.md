# reports/

Báo cáo của Codex, Claude và PO, chia theo ngày: `reports/YYYY-MM-DD/`.

- Ngày chỉ dùng để xếp file. **Task ID (`T00` … `T15`) mới là đơn vị quản lý công việc.**
- Tên file theo `docs/AGENT_RULES.md` mục 5 và chính sách mục 8.
- Report phải ngắn, không chép lại Task Record.
- Report đã nộp không sửa nữa; muốn bổ sung thì tạo report vòng mới.
